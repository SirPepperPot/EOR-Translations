# EOR Translations

Community-managed localization packs for Enhanced Overhaul Remix (For The King II).

The English source of truth is maintained in the main EOR repository. Translation changes are reviewed before publication. Never change localization keys; translate values only. Preserve `{0}` and other format placeholders.

The `languages/` directory contains plain JSON string dictionaries. Korean (`ko.json`) is reserved for community translations. English fallback is handled by EOR.

**Status:** Repository initialization; game startup auto-update support requires integration and testing in the main EOR mod.
